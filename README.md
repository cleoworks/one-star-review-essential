Entry for the make.fun bounty **One-Star Review of Something Essential**: one
single-line deadpan one-star review, at most 160 characters, of an everyday
essential.

The program (`main.py`, Python 3.13, no dependencies) writes the review to
`/output/entry.txt`:

> One star. My thumbs type the wrong letter with total confidence, then blame autocorrect.

88 characters, plain ASCII, no exclamation mark. Run it with `python3 main.py`.
